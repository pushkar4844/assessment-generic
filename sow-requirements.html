SOW Requirements

First Abu Dhabi Bank (FAB) — AWS Cloud Internet Breakout Technical Scope of Work

1. Objective

FAB requires an independent technical assessment of the AWS Cloud Internet Breakout architecture before production rollout, covering design, routing, security controls, resilience, migration readiness and key risks.

2. Technical Scope of Work

2.1 Architecture Review

  • Review the design against FAB security, availability and operational requirements.
  • Validate VPCs, CIDRs, subnets and Availability Zone placement.
  • Assess Transit Gateway, route tables, propagation and routing controls.
  • DNS architecture and name resolution.
  • Internet Gateway and NAT Gateway design.
  • Application Load Balancer, Network Load Balancer and Gateway Load Balancer design.
  • Review Terraform or CloudFormation against the approved design.

2.2 Traffic Flow Validation

  • Review inbound, outbound and east-west traffic flows.
  • Validate L3/L7 paths, inspection, proxy, firewall and load-balancing dependencies.
  • Verify routing symmetry and return-path design.
  • Review service insertion and inspection flows.
  • Confirm security-control placement and traffic steering.

2.3 High Availability and Resilience Review

  • Review multi-Availability Zone architecture and fault-tolerance mechanisms.
  • Assess Availability Zone, network virtual appliance and Gateway Load Balancer target failure scenarios.
  • Review route convergence, recovery behavior and stateful session impact.
  • Identify asymmetric-routing risks.
  • Define practical failover scenarios and expected results for UAT.

2.4 Third-Party Integration Review

Review integration with AWS networking and third-party security components, including:

  • Network virtual appliances and firewalls.
  • IPS/IDS and WAF solutions.
  • Proxy and security inspection services.
  • GENEVE compatibility, health checks, routing, return paths and inspection-chain dependencies.

2.5 Migration and Cutover Readiness Review

  • Review the migration strategy and traffic switchover sequence.
  • Review rollback procedures, triggers and service-restoration criteria.
  • Identify cutover dependencies and potential traffic black-hole windows.
  • Define go/no-go criteria.
  • Provide production-readiness recommendation with risks and prerequisites.

4. Partner Responsibilities

  • Assign experienced AWS network and security consultants.
  • Complete scope items and submit deliverables for FAB acceptance.
  • Include evidence, impact, risk rating, recommendation, dependency and owner for each finding.
  • FAB review comments are resolved or formally recorded.
  • Submit final reports, diagrams, risk register and editable artefacts.
